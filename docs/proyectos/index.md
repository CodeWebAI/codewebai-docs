# Proyectos

La sección **Proyectos** reúne la información funcional, técnica y operativa de los productos de CodeWebAI y de las soluciones desarrolladas para nuestros clientes.

Aquí se explica qué problema resuelve cada solución, cuáles son sus módulos y cómo se desarrolla, entrega y mantiene.

## Contenido

Cada página puede incluir:

- Objetivo, alcance y usuarios.
- Módulos y funcionalidades.
- Arquitectura, tecnologías e integraciones.

## Organización

Los proyectos se organizan en dos grupos:

- **Productos:** soluciones propias de CodeWebAI, como EducheckAI.
- **Clientes:** soluciones desarrolladas para organizaciones externas.

Cada solución tendrá su propia página y podrá dividirse en documentos adicionales cuando sea necesario.

## Proceso

El trabajo seguirá, de forma general, este recorrido:

```text
Idea o necesidad
	-> Levantamiento de requerimientos
	-> Definición de alcance y módulos
	-> Diseño y desarrollo
	-> Pruebas y validación
	-> Entrega o despliegue
	-> Soporte, mantenimiento y evolución
```

El recorrido puede adaptarse a cada caso. Los cambios, decisiones y acuerdos deben quedar registrados.

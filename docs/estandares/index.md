# Estándares
![IMAGEN](../assets/img/estand.jpg){: left="160px"}
Los estándares de desarrollo establecen lineamientos y buenas prácticas
para mantener una forma de trabajo organizada, consistente y segura
dentro de los proyectos de Code Web AI.

En esta sección se documentan los principales procesos y criterios
utilizados durante el desarrollo, despliegue y mantenimiento de los
proyectos.

De esta manera los integrantes y nuevos integrantes de Code Web AI podran tener una base de trabajo y desarrollo para su crecimiento profesional dentro de la empresa.

# Gestión y seguimiento de proyectos

El HelpDesk conecta las solicitudes del cliente con la planificación del proyecto. No sustituye la gestión de proyectos, pero conserva la trazabilidad de las necesidades, decisiones, bloqueos y compromisos que llegan por soporte.

## Temas que debe controlar

- Alcance y objetivos acordados.
- Personas responsables y canales de comunicación.
- Requerimientos, solicitudes de cambio y aprobaciones.
- Entregables, fechas objetivo y dependencias.
- Riesgos, bloqueos y decisiones pendientes.
- Incidencias que afectan el cronograma.
- Estado de ambientes, versiones y despliegues.
- Criterios de aceptación y validación del cliente.

## Seguimiento de una solicitud del proyecto

```text
Necesidad del cliente
    -> Requerimiento documentado
    -> Estimación y revisión de alcance
    -> Aprobación o priorización
    -> Tarea asignada
    -> Desarrollo y pruebas
    -> Entrega al cliente
    -> Validación y cierre
```

## Reuniones y acuerdos

Después de una reunión se deben registrar la fecha, asistentes, decisiones, tareas, responsables, fechas objetivo y preguntas pendientes. Un acuerdo verbal que afecta alcance, costo o fecha debe confirmarse por un canal trazable.

## Reporte de estado

Un reporte periódico puede incluir:

- Estado general: normal, en riesgo o bloqueado.
- Avances desde la última actualización.
- Próximas actividades.
- Entregables completados y pendientes.
- Riesgos y bloqueos.
- Decisiones requeridas del cliente.
- Cambios de alcance o fecha.
- Incidencias abiertas relevantes.
